# DoraHacks submission text

**Project name:** IdleWatt (working name)

**Short description (2–3 sentences):**

IdleWatt is an on-chain registry and live dashboard, built as a Gno realm, for idle compute nodes like home GPU boxes, CPU machines and, someday, parked vehicles that want to rent spare capacity on decentralized networks such as Akash. Operators register nodes, send signed heartbeats, flip between "parked & plugged in" and "driving," and log simulated jobs whose earnings the realm computes itself. A fairness pool inspired by AtomOne's Nakamoto Bonus splits 14% of every job equally across all online nodes, so small nodes aren't drowned out by big ones. All data is simulated or self-reported, and there's no Tesla or Akash integration yet.
